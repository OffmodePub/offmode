# digest — 오늘의 이슈/해결 Slack 다이제스트

사용자가 이 스킬을 호출하면 다음 절차를 수행한다.

## 1. 스코프 결정 + 트랜스크립트 수집

사용자 발화에서 **스코프**를 먼저 판단:

| 사용자 표현 | 스코프 |
|---|---|
| "정리해줘", "/digest", "오늘 거" | **오늘 전체** (default) |
| "지금 세션만", "이번 대화만", "방금 거", "현재 세션" | **현재 세션만** |
| "최근 N일", "어제부터" 등 | **기간 지정** |
| 세션 ID/UUID 일부 명시 | **특정 세션** |

스코프에 따라 다른 파일을 읽는다:

**현재 세션만**:
환경변수 `CLAUDE_SESSION_ID` 또는 시스템 컨텍스트에서 현재 sessionId 추론.
없으면 트랜스크립트 디렉토리에서 **mtime이 가장 최신인 `.jsonl`** 한 개 선택.
```bash
TRANSCRIPT_DIR="$HOME/.claude/projects/-Users-calla20031-offmode"
ls -t "$TRANSCRIPT_DIR"/*.jsonl | head -1
```

**오늘 전체**:
```bash
find "$TRANSCRIPT_DIR" -maxdepth 1 -name "*.jsonl" -newermt "$(date +%Y-%m-%d)" -print
```

**기간 지정**:
```bash
find "$TRANSCRIPT_DIR" -maxdepth 1 -name "*.jsonl" -newermt "N days ago" -print
```

**현재 세션만**일 때는 상세도를 더 높이고 (그룹핑 대신 시간순 흐름 + 코드/명령어 인용 포함), 다른 스코프에서는 그룹핑 요약 위주로.

(다른 프로젝트에서 호출된 경우 `pwd`를 변환해서 경로 추론: `/` → `-`, 첫 글자 `-` 유지)

## 2. 이슈/해결 추출

각 트랜스크립트를 읽고 다음 패턴을 식별:

- **이슈**: 사용자가 보고한 문제, 버그, 에러, 막힌 지점, "안 돼", "왜 X", "수정해줘" 류
- **해결**: 어시스턴트가 제시한 원인 진단 + 수정 방법 + 적용된 패치 (커밋, 파일 수정, 명령어 실행 등)
- **결정**: 사용자와 합의된 방향 전환, 선택지 결정

대화 흐름에서 "문제 → 원인 → 해결"이 한 묶음으로 정리되도록 그룹핑.
같은 주제로 묶을 수 있으면 묶고, 별개면 분리.

## 3. Slack 메시지 포맷

한국어, 마크다운 (Slack mrkdwn) 사용.

### A. 오늘 전체 / 기간 (요약 모드)
간결하게, 세션 묶음별로 항목 1~2줄씩.

```
📋 *오늘의 작업 다이제스트* — YYYY-MM-DD

*1. [주제 한 줄 제목]*
• 이슈: ...
• 해결: ...

*2. [주제 한 줄 제목]*
• 이슈: ...
• 해결: ...
```

### B. 현재 세션만 (상세 모드)
같은 한 세션을 깊게. 시간 흐름대로 "무엇을 시도했고 → 어떤 에러가 나왔고 → 어떻게 풀었는지" 까지 포함. 필요하면 핵심 명령어/코드 스니펫(```)도 인용.

```
📋 *현재 세션 상세 다이제스트* — YYYY-MM-DD HH:MM

*세션 주제*: [한 줄]

*1. [단계 제목]*
• 상황: ...
• 시도: ...
• 결과/해결: ...
`핵심 명령어 또는 파일 경로`

*2. [단계 제목]*
...

*최종 상태*: [무엇이 완료/남아있는지]
```

이슈가 없으면 "큰 이슈 없이 진행됨" 같이 한 줄로.

## 4. Slack 전송

`.env`에서 `SLACK_WEBHOOK_URL` 읽어서 POST. 값은 화면에 출력하지 않는다.

```bash
set -a; source /Users/calla20031/offmode/.env; set +a
curl -sS -X POST -H 'Content-type: application/json' \
  --data "$(jq -nc --arg t "$MESSAGE" '{text:$t}')" \
  "$SLACK_WEBHOOK_URL"
```

(`MESSAGE`는 위에서 만든 본문. `jq`로 JSON escape — 따옴표/줄바꿈 안전)

응답이 `ok`면 성공. 아니면 사용자에게 응답 그대로 표시.

## 5. 사용자에게 보고

전송 완료 후 다음만 출력:
- 전송된 항목 개수
- Slack 응답 (`ok`)
- 본문 미리보기는 따로 보여주지 않음 (Slack 채널에서 확인)

원하면 사용자가 "본문도 보여줘"라고 추가 요청.
